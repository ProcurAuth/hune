Specification

The eight parts of the specification of Hune: the format of a document, the API, the query engine, the page, the access rules, the configuration and the tests.

This page comes from docs/SPECIFICATION.md in the repository.

The specification of Hune has eight parts. It describes the product that the code implements, and the rules that the tests check. It is a draft, version 0.1. The implementation status lists the differences between the code and the text.

The key words MUST, MUST NOT, SHOULD and MAY follow RFC 2119 and RFC 8174 when they are in capital letters.

Rules of the text

  • A numbered paragraph N.M keeps its number in all later versions. A paragraph that leaves the text keeps its number with the word "Unused".
  • A cross-reference gives a section number (for example "section 11") or a paragraph number (for example "5.14").
  • A code span holds an exact name: a key, a member, a route, a type or a command.
  • The code and the tests cite the paragraph numbers.
